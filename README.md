## 三、宿主机 50% 性能隔离安全屏障

在边缘机组 SCADA 服务器上运行时，严禁算法满载抢占控制系统资源。本系统内置硬件隔离机制：

- **CPU 核心亲和性绑定 (50%)**：自动探测宿主机逻辑核心数，例如在 8 核机器上严格绑定前 4 核 (`Affinity Mask: 0x0F`)，空出其余核心专属保障风机主控与 SCADA 通信。
- **PyTorch 线程限制**：通过 `torch.set_num_threads` 限制底层算子并发度，杜绝 CPU 满载抢占。
- **进程优先级降级**：进程调度优先级自动设为 `BELOW_NORMAL_PRIORITY_CLASS`，确保操作系统核心服务优先调度。
- **内存安全使用硬封顶**：限制最大内存占用不超过物理内存的 50%（如 32GB 机器封顶 16GB），超出自动触发垃圾回收与缓存清理。
- **动态实时调节**：支持在 Web 管理后台直接调节 CPU 核数与内存阈值，即时生效无需重启。

## 五、模型权重配置说明

本系统模型由 **预训练声学基座骨干 (Backbone)** 与 **风电碰撞微调分类头 (Transfer Head)** 组成：

1. **微调分类头权重 (`*_transfer.pt`)**：
   - `models_repo/03K-声学大模型-Dasheng自监督通用音频大模型/weights/dasheng_official_transfer.pt`
   - `models_repo/03U-声学大模型-ECHOv2频带自监督声学异常检测大模型/weights/echov2_transfer.pt`
   - `models_repo/03R-声学大模型-GRAM-Mono混响自适应模型/weights/gram_mono_transfer.pt`  
   *微调分类头（约 1.5~2.4MB）已直接包含在代码仓库中。*

2. **自监督预训练骨干网络 (`model.safetensors`)**：
   - 03K (Dasheng-Base, 89M): 325.97 MB (源: `mispeech/dasheng-base`)
   - 03U (ECHOv2, 82M): 82.18 MB (源: `yucongzh/echo-small-v2`)
   - 03R (GRAM-Mono, 86M): 424.65 MB (源: `labhamlet/gramt-mono`)  
   *系统内置自动下载引擎：运行 `1_一键部署环境(安装依赖).bat` 或 `0_一键下载模型权重.bat` 即可全自动通过国内高速镜像源完成下载与校验。完全离线环境亦可手动放置。*

## 七、现场音频监听与接入

将机舱或轮毂采集的 20 秒音频文件（支持 `.bin` 或 `.wav`）拷贝至 `incoming_audio` 目录（或通过管理后台自定义的监听路径），后台守护线程将在 1 秒内自动触发 3 模型协同诊断，处理完成后自动备份归档至 `incoming_audio/processed` 对应的分类子目录：
1. `01_全票确诊碰撞_3票/` (重大金属撞击红警)
2. `02_多数表决碰撞_2票/` (多数确诊碰撞橙警)
3. `03_孤立扰动拦截_1票/` (偶发扰动绿标放行)
4. `04_正常平稳底噪_0票/` (平稳运行正常底噪)
5. `05_硬件削顶死锁/` (传感器供电轨饱和截幅)
6. `06_现场机组启动工况/` (CPD 阶跃爬升起机工况放行)
7. `07_现场机组停机工况/` (CPD 阶跃下降停机工况放行)

## 八、被部署电脑自动更新与版本维护体系

为了保障风电机组现场部署的工控机随时能够同步最新的算法门禁、模型权重优化与缺陷修复，系统提供了 **3 种全自动化更新渠道**：

### 方式 1：Web 后台管理界面一键在线更新（推荐，免远程桌面）
运维人员无需通过 TeamViewer/向日葵或 Windows 远程桌面登录现场主机：
1. 直接在办公电脑浏览器访问现场机组的 Web 后台：`http://<工控机IP>:8088/admin`
2. 切换至 **【引擎配置与资源监控】** 标签页底部的 **“系统在线自动更新与版本维护”** 卡片；
3. 点击 **“🔍 检查远程最新版本”**，系统即刻比对 GitHub 远程主线版本与本地 Commit，并展示更新日志预览；
4. 点击 **“🚀 立即在线升级并热重启”**，后台将全自动拉取最新代码、同步依赖、校验模型，并在 25 秒内自动重启恢复监测。

### 方式 2：现场双击一键批处理更新脚本
若在现场调试，直接双击运行：
```cmd
5_一键在线更新系统.bat
```
脚本将交互式展示更新提交对比、拉取最新代码并平滑重启。

### 方式 3：Windows 计划任务每日夜间静默自动更新（无人值守运维）
适合风电场大批量部署、长期无人值守运行的边缘工控机：
1. 右键以管理员身份运行：
   ```cmd
   开启每日自动更新计划任务.bat
   ```
2. 系统将自动注册 Windows 计划任务 `WindTurbine_AudioDetect_AutoUpdate`，在 **每日凌晨 02:00（风机低风速或运维窗口）** 自动静默联网检测更新；
3. 只有当 GitHub 主线存在新版本提交时，才会执行拉取和秒级热重启；若已是最新版本则完全不干扰当前监控服务；
4. 如需关闭，随时双击运行 `取消自动更新计划任务.bat` 即可一键注销。
